## Display model

The region is the prompt plus the rendered command, laid out from column 0. `shell/engine/src/terminal/display.rs` keeps the painted region bytes, the terminal cursor, `bottom` (the deepest region row written) and `top` (the first region row still on screen). Writing below the last screen row scrolls, so `top = max(top, bottom - (rows - 1))`. That holds exactly, wherever the prompt started, so no cursor-position report is needed.

- A render repaints from the first changed row, clamped to `top`. It clears below that row and stops before a row that would scroll the caret's row off the screen. A caret move only moves the cursor.
- If the caret's row is above `top`, the screen's top row is relabelled as the caret's row and repainted. History keeps its earlier copy of those rows, which a terminal cannot edit.
- If the caret's row is below `bottom`, the editor paints from `bottom`. `finish` also paints from there when the bottom rows were never painted.
- If the command ends exactly at the right margin, the editor writes a space so the terminal soft-wraps into the next row. The space is kept in the painted bytes and replaced by the next echoed character.
- `finish(interrupted)` moves below the last row before writing `\r\n` or `^C\r\n`. A plain Enter on the last row writes exactly `\r\n`, which keeps A2's byte assertions.
- Ctrl+L writes `CSI H CSI 2J` and paints from row 0.
- A resize recounts the cursor and end with the new width. It assumes the terminal keeps the command's end at the bottom of the screen.

Widths: `terminal/width.rs` is generated by `scripts/terminal-widths.ts`, which sweeps every codepoint through the pinned libghostty-vt (`7b11f3d`) with mode 2027 off. `unicode-width` 0.2.2 disagrees with the terminal on 1,144 codepoints, including the flag regional indicators (2 cells vs 1), Mc spacing marks, Unicode 17 Tangut and U+00AD. Native Ghostty.app enables mode 2027 by default. ghostty-webgpu does not. If ghostty-webgpu changes its default, the editor needs grapheme widths.

## Contracts for integration

- `Editor::begin(prompt, Geometry)`, `resize(Geometry)` and `redraw()`, plus `finish(bool)`. A2's `finish_prompt` calls `finish`. A host interrupt calls `clear()` and then `finish(true)`.
- New guest import `shell_terminal.rows()`.
- A2's `paint_line` (EL plus CRLF) is now `paint_text`, which writes CRLF for a newline. Every repaint already clears below its first row.
- A5 `e4465c4e` trial merge: `runtime_main.rs` merges cleanly and keeps `phase(value, status)`. `guest-imports.ts`, `worker.ts` and `scripts/test-own-shell-terminal.ts` conflict only because `rows()` sits next to A5's two-argument `phase`. Keep both sides.
