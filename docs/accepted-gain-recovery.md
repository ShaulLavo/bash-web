The authenticated GitHub adapter checks the exact terminal native failure in run 40157800143 attempt 1, both skipped producers, and absence of normal raw and floor artifacts. Evidence errors never mean absence. The adapter then verifies PR102's landed merge, original tested merge and distinct trees, clean automatic composition, original ten successful Shell jobs before merge, uploaders and artifact digests. Its floor was published after PR102 merged and is not required to predate that merge.

The union is an `AcceptedGainFloor`. It is not an f6 observation, score, green result or source-equivalence proof. Qualification still requires the current candidate's genuine Waffle raw artifact. Private in-process preparations and observations cannot be manufactured by a serialized object. Each fold reconstructs authority from GitHub, checks artifact expiry, and verifies the current producer's binding and observation order.
